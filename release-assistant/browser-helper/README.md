# Dorado → DistroKid browserhulp

Deze Chrome/Edge-extensie neemt metadata uit de Dorado Release-assistent over op de geopende DistroKid-uploadpagina.

## Installeren op Windows

1. Download deze map naar de computer en pak hem uit.
2. Open `chrome://extensions` (Chrome) of `edge://extensions` (Edge).
3. Zet **Ontwikkelaarsmodus** aan.
4. Kies **Uitgepakte extensie laden** en selecteer deze `browser-helper`-map.
5. Zet de extensie eventueel vast naast de adresbalk.

## Gebruik

1. Controleer de release in de webapp en kies **Kopieer voor browserhulp**.
2. Open de nieuwe-releasepagina van DistroKid en log zelf in.
3. Open de extensie, plak het pakket en kies **Vul DistroKid in**.
4. Controleer alle velden. Kies audio en hoes zelf en beantwoord de actuele rechtenvragen.
5. Publiceer uitsluitend zelf.

De extensie bevat bewust geen code die de definitieve upload- of publicatieknop aanklikt.
